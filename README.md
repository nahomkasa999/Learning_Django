# Learning Django

Learning Django, lessons 2–10 — ending in a working inventory management app.

## What it covers

- Django lessons 2–10 (initial commit)
- An inventory management app: models, forms, views, and templates for managing items
- CRUD for items — create, update, delete, and view
- Search in the inventory dashboard
- Responsive UI with CSS

## Stack

Python · Django · Pipenv (`Pipfile` / `Pipfile.lock`)

## Run it

```bash
pipenv install
pipenv run python manage.py runserver
```

Run the server from the Django project folder in the repo.
